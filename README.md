# FTU Vasculature Visualization Code

This folder contains the code and supporting notebooks used to create the final organ vasculature and functional tissue unit (FTU) visualizations.

## Project overview

The visualization workflow separates the biological data from the visual design:

1. The organ CSV files provide the FTUs, vessel names, ontology identifiers, pathway order, and arterial and venous connections.
2. HRA ASCT+B version 2.5 is used to validate anatomical terminology, vessel classifications, and FTU hierarchy.
3. The Python scripts build and validate the vascular network.
4. Reference-style and Dr. Griffin revisions determine the layout, typography, FTU containers, and symbols.
5. The Bézier scripts create the final smooth vessel connections without changing the validated vessel nodes and edges.

## Python files

### `organ_vasculature_biological_vega.py`

Reads the organ CSV files, constructs the vessel and FTU network, classifies the vessels, and validates the resulting nodes and connections against the source data and HRA ASCT+B.

### `organ_vasculature_reference_style.py`

Applies the original scientific reference layout and visual style to the validated vascular model. This step changes the presentation, not the underlying biological relationships.

### `organ_vasculature_griffin_revision.py`

Applies Dr. Griffin's requested revisions, including FTU placement, vessel-node conventions, typography, canvas size, and organ-specific layout adjustments.

### `create_remaining_bezier_variants.py`

Creates the final smooth Bézier-curve versions for the kidney, liver, large intestine, small intestine, lung, mouth, and skin. It uses the validated model and revised layouts while preserving the vessel-node and edge relationships.

### `create_prostate_bezier_variant.py`

Creates the final prostate Bézier version from the manually refined prostate SVG. It changes selected connector paths while preserving the remaining SVG content.

## Jupyter notebooks

### `HRA_OrganTree_ftus_biological_overlay.ipynb`

Documents the biology-first vascular model and was used to review the vessel pathways, FTU containment, classifications, and validation results.

### `HRA_OrganTree_ftus_exact_overlay.ipynb`

Documents an earlier validation stage used to verify that the source vessel nodes and connections were retained in the visualization model.

The notebooks provide context and validation history. The final Bézier SVG files were generated by the standalone Python scripts rather than directly by the notebooks.

## Input data

### `A5-data/`

This folder contains one CSV file for each organ:

- Kidney
- Liver
- Large intestine
- Small intestine
- Lung
- Mouth
- Prostate
- Skin

Important CSV columns include:

- `FTU` and `FTUID`: the FTU name and ontology identifier
- `Vessel` and `VesselID`: the vessel associated with the FTU
- `PathStep`: the vessel's position in the vascular pathway
- `PathVessel` and `PathVesselID`: the vessel at each pathway step
- `Type`: the arterial or venous classification supplied by the source data

Negative `PathStep` values describe the pathway supplying the FTU. Step `0` represents the vessel inside the FTU. Positive values describe the drainage pathway away from the FTU.

## HRA reference data

The scripts use the following HRA ASCT+B version 2.5 release for anatomical validation:

`https://cdn.humanatlas.io/hra-asctb-json-releases/hra-asctb-all.v2.5.json`

The downloaded file is expected to be named:

`hra-asctb-all.v2.5.json`

## Reproducibility note

The scripts were originally run with the organ CSV directory named `organs_with_ftu_6_csv` inside the project folder. In this shared package, the CSV files are stored in `A5-data`.

To rerun the scripts without editing their input paths:

1. Place the scripts and `hra-asctb-all.v2.5.json` in the same directory.
2. Place or copy the CSV files into a project subfolder named `organs_with_ftu_6_csv`.
3. Run the reference or revision generator from an environment containing the required Python packages.
4. Run `create_remaining_bezier_variants.py` with the project directory and a separate output directory.

The final positions and curves are presentation decisions based on the supplied scientific reference style and Dr. Griffin's feedback. They are not anatomical coordinates obtained from HRA.
